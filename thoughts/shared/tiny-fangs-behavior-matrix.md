## How to Read This Matrix

- **covered** means a direct automated assertion exists for the exact contract named in that row. A fixture that merely describes a state, a source-code scan, or a test of a neighboring helper is not credited.
- **missing** means the direct automated contract does not exist. The “New direct target” cell names the required regression test.
- **manual-pending** is reserved for a visual, physical-device, or assistive-technology check that cannot be honestly closed by the current automated evidence alone.
- **Known gap, covered** means a direct characterization test freezes a defect as observed. It does not mean the behavior is correct.

Viewport/input abbreviations:

- **D:** 1672×941 desktop, mouse and keyboard
- **M:** 390×844 portrait mobile, touch/pointer
- **L:** 844×390 landscape mobile, touch/pointer
- **T:** 1024×768 tablet, touch and keyboard
- **MP×2:** two isolated browser contexts against the real WebSocket server

## Exact Missing Seams

- `src/main.js` is a side-effectful entry module. Input handlers, preview functions, timer creation, result functions, and overlay functions are module-local and cannot be imported without mounting the complete page. Their direct targets must therefore be Playwright tests until a narrow lifecycle/input coordinator is introduced.
- Deck preview now routes `pointercancel` through the existing release cleanup, but a reusable listener-owner seam still does not exist.
- Grave-card hold handlers are generated as inline `pointerdown/up/leave` attributes and likewise omit `pointercancel`.
- Timer creation and reading have no shared owner API. `clearGame()` is an isolated disposer, not a mounted lifecycle contract.
- Event playback still has no result presenter dependency or stable-UID target registry. `gameOver` ownership and cross-render bench identity remain future seams.
- `queueUpdate/processUpdate` and `createSoloDispatch` are sufficiently injected and exported; Task 08 uses those existing seams directly and requires no production refactor.

This matrix is exhaustive for the currently discoverable public journeys and contracts, but it is not a claim that Phase 1 parity is complete. “covered” rows identify durable direct evidence. “missing” and “manual-pending” rows are the ordered regression backlog that must be closed before the classic renderer can be retired.
