## Pattern Learned
When finding hardcoded checks for specific cards:
1. Check if a trigger system already exists for that event type
2. If so, convert the hardcoded check to use the trigger system
3. Add any missing flags (like `perTurn`) to the trigger processor
4. Update all direct damage sources to emit the appropriate trigger

## Current Attack Flow
```
beforeAttack → damage calc → beforeDamage → apply damage → 
checkLethalDamage (Fortify + onLethalDamage triggers) → 
onHit (attacker sustain) → afterAttack (defender retaliation) → KO
```
